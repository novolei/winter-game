# 统一重开复位契约报告

日期：2026-08-14

状态：完成

## 结果

`GameState` 现在可以在一次尝试已经结算后安全调用 `restart_run(seed)`。重开采用一个同步的值类型事件 `game.run_reset`，顺序固定为：

1. 校验生存体、七日时钟和日程仍可启动；
2. 确定下一局种子并发布 `game.run_reset`；
3. 各状态所有者清理自己的上一局数据；
4. 启动新的生存体与第 1 天时钟；
5. 发布新的 `game.run_started`。

该边界不让 `GameState` 直接引用库存、路线层或信标网络，继续满足跨系统通信只经 `EventBus` 的约束。

## 被复位的状态

- `FuelEconomy`：清空背包数量、质量和燃料总值，保留 `.tres` 物品目录；
- `SurvivalRouteLayer`：恢复所有已拾取节点的可见性、监测和碰撞，使下一局可再次拾取；
- `BeaconNetwork`：清空五座信标燃料和火焰，清除温暖恢复、风状态和上一局反馈，恢复第 1 天解锁边界；
- 随机性：信标网络从下一局 `seed` 重新播种，避免重开后继承上一局随机序列位置。
