# 暂停菜单（ESC）精修设计 · 动效工艺优先

*2026-08-13 · 方案 A（动效工艺优先）· 上级文档：[UI/UX 设计文档](2026-08-12-winter-survival-ui-design.md) §4.3*

本文档是 ESC 暂停面板「内容补全 + 视觉升级」的验收标准。方向：**纪念碑谷式的唯美、优雅、丝滑、简约精致**，不改动现有空间化排版架构（`ExitMenu` Canvas 命中层 + `SpatialPauseMenu` 3D 深度排版 + 电影化推镜），全部新增投入集中在**动效编排与设置面板工艺**。

## 范围裁决

| 做 | 不做 |
|---|---|
| 菜单新增「设置」入口 + 三项设置子页 | 「放弃这一夜」（项目尚无主菜单可回，暂缓） |
| 级联动效编排（打开/关闭/切页/调值） | 纪念碑谷式构图重组（方案 B，未选） |
| 排版层级升级 + 焦点三重反馈 | 矩形滑块/底板（规则 1）、暖色 UI 态（规则 3） |
| 设置持久化（user://） | 相机随鼠标微差（会"晕"，仅排版层微差） |

## 1. 菜单结构与导航

### 1.1 主页（三选一，竖排在左侧呼吸边界内）

```
第 四 日 · 夜              ← Display，字重提升、字号加大（层级第一）
─────────────            ← 细线，打开时从左向右展开
天光尚余  03:14            ← caption 缩小、明度降低；数字用 Instrument 等宽字

继　续
设　置                    ← 新增
退出游戏
```

### 1.2 设置子页（第三状态，与主页/确认页同级，共用 StateSlot 舞台）

```
设　置                    ← 比主页标题小一号

提示停留时长   1.0× ─────○───   ← ←→ 调节，0.5×–3.0×，步进 0.25
提示笔画加粗   关  ─○─────────   ← 开/关
屏 幕 震 动    开  ─────────○─   ← 开/关

ESC   返回暂停
```

- 设置行 = 名称（Interface 字）+ 值（Instrument 等宽字）+ 一根带刻度的细线轨道
- 当前调节行获得焦点处理；其余行降到 `opacity_steps[2]`（48%）

### 1.3 导航模型

- ↑↓ 移动焦点；Enter/点击确认；←→ 在设置行调值；ESC 逐级后退（设置 → 主页 → 关闭菜单）
- 键盘焦点、鼠标悬停、Canvas 隐形按钮、3D 空间副本四者保持**同一焦点源**（沿用并扩展现有 `set_focus` 同步模式）
- 确认退出的 180ms 防误触守卫（`CONFIRM_GUARD_MSEC`）保留

## 2. 动效编排与微交互（本方案的核心投入）

### 2.1 打开 · 级联呵气（Staggered Bloom）

- 现状：内容层整体 bloom。改为**逐行级联**：状态行 → 细线（从左扫开）→ 剩余时间 → 菜单三项依次落下
- 每行延迟 70ms（由 `bloom_seconds` 的比例推导，不硬编码秒数）；每行自身仍是完整「呵」曲线：opacity 0→1、位移 +8px→0、QUINT EASE_OUT
- 相机推镜保持 1.85×，曲线与级联同步收束——最后一行落定与相机停稳同帧
- 音效：`ui.bloom` 一声；级联不重复发声（规则 6：每次呵气一个声音，不是每行一个）

### 2.2 焦点 · 三重反馈（全部冷色，遵守规则 3）

1. 细线下划线从左生长（现有，保留）
2. **字重呼吸**：NotoSerifSC-VF / Inter-VF 均为可变字体，焦点项字重 +100，失焦回落——零贴图成本的精致感
3. **轻微上浮**：焦点项 y −2px；非焦点项降到 `opacity_steps[2]`

### 2.3 设置行调节

- ←→ 每步进：值数字做 1.0→1.03→1.0「落定脉冲」（scale，200ms），轨道刻度逐格点亮
- 步进音效 `ui.move`；到达档位边界时用 `ui.back` 的音高变体提示，**不给视觉抖动**

### 2.4 关闭 · 逆向消散

- 现状：整体淡出。改为**严格逆序级联 drift**：菜单项先散（向上 −8px、opacity→0），状态行最后散，细线收回起点
- 相机回归与最后一行的散同帧完成；QUAD EASE_IN 不变

### 2.5 鼠标微差（Parallax，极克制）

- 空间副本（Label3D 组）对光标做 ≤6px 反向追随，指数平滑（沿用 `LINE_RESPONSE` lerp 模式）
- 相机不动；窄屏/compact 模式自动关闭

### 2.6 状态切换（主页 ↔ 设置 ↔ 确认）

- 离场组逆序级联 drift（快，`drift_fast_seconds`）；进场组级联 bloom
- 两面板共享同一舞台，读作"同一组字重新排布"，而非换卡片

## 3. 数据流与持久化（数据驱动）

```
data/ui/accessibility_settings.tres      ← 新增：三项设置定义（id、显示名、档位、默认值、步进）
src/definitions/accessibility_setting.gd ← 新增：单项定义 Resource（id、label、min/max/step 或 enum 档位）
src/ui/settings_store.gd                 ← 新增：静态类，读写 user://ui_settings.cfg
```

- 新增一项设置 = 只加一个 `.tres` 条目，零 `.gd` 改动
- 三个消费点：
  - **提示停留时长** → `UILayer.set_time_scale()` 的输入源（机制已存在，接入即可）
  - **提示笔画加粗** → 字重与线宽 ×2 开关（outline_size、hairline 高度）
  - **屏幕震动** → `CameraRig` 震动的布尔门禁（不改震动逻辑本身）
- 用 `ConfigFile` 存 `user://ui_settings.cfg`：玩家手改友好，损坏可整文件丢弃回退默认

## 4. 错误处理

| 情况 | 行为 |
|---|---|
| 配置文件损坏/缺失 | 静默回退默认三项，不弹错误 |
| 可变字体字重轴不可用 | 焦点字重回退为纯透明度对比 |
| `WorldClock` 缺失（测试环境） | 状态行占位"第 一 日 · 昼"（现状一致） |
| 相机 rig 缺失 | 跳过微差与推镜，纯排版模式（沿用 `has_camera()` 守卫） |

## 5. 测试计划

1. `test_pause_menu_states.gd` — 三状态切换、ESC 逐级后退、Canvas↔Spatial 焦点同步
2. `test_settings_store.gd` — 持久化往返、坏档回退默认、档位边界 clamp
3. `test_pause_choreography.gd` — `advance()` 驱动：级联延迟按序、关闭严格逆序、焦点字重/透明度目标值
4. 设置消费点测试 — time_scale 接入、笔画加粗开关、震动门禁
5. 既有退出菜单测试全部保持绿色（焦点守卫、防误触等不回归）
6. 每次交付跑 `bash tools/run_tests.sh <总数>`，控制台必须干净
