Breath — a UI language for The Last Long Night

GDD 第三支柱写的是「沉默即叙事——没有 HUD」。所以这个游戏 有 UI，但它没有 HUD：屏幕的常态是零像素，元素只在变化发生时呵出来， 说完就散掉。判据只有一句——这个元素消失之后，玩家是否仍然必须看世界？

Motion Doctrine

呵 · 持 · 散

UI 照抄这个游戏自己的法则。GDD §7 给天气定的铁律是三段式： 预兆期 → 持续期 → 消退期，理由是「无预警的风暴不是难度，是不公平」。 UI 用同一套语法，理由相同——突然出现又突然消失的元素是对玩家注意力的偷袭。 没有任何元素可以跳过其中任何一段。

寒流事件期间，上表所有时长 ×1.4。

GDD 给寒流的预兆是「空气变得极静」。所以 UI 也变慢——每个提示的绽放与消散都拖长四成。 玩家不会意识到自己读到了什么，但他会感觉到有什么不对。 等他反应过来时，他已经在雪地上留下一条清晰的足迹了。

安静既是危险的预兆，也是危险的原因——这句话现在也是一条 UI 规范。

颜色

UI 代码里不得出现十六进制字面量。下表每一格的值都必须从项目的调色板资源里读出来， 与着色器读的是同一份。规则 3 是把第一支柱救回来的那一条： UI 里的一个暖像素，必须和世界里的一个暖像素意思相同。

Typography · 中英双语，中文为主

字体

三族，全部 SIL OFL 授权，可随游戏发行。 字距是「空灵」的真正来源，比字号重要——窄字距读作紧张，宽字距读作安静。 展示级别的 +0.22em 在一般 UI 里是过分的；在这里它是规格。

仪表族必须是等宽且开启表格数字（tabular figures）。 Tab 读数每帧都在变，比例数字会让 68% 变成 71% 时整行左右抖动——这在一个讲究安静的界面里是致命的噪音。 这是硬要求，不是偏好。

Icons · Gemini 生成 · 白色 RGB + 亮度 alpha

图标

每张图都是纯白 RGB + 亮度写入 alpha，所以一张文件可以在 Godot 里用 modulate 染成十二色表里的任意一色。造型语言跟着世界走：美术圣经规则 2 说建筑是 3-8 个凸体块，所以图标也是几块直边凸体拼出来的，不是圆润的通用图标。

The Laws

六条硬规则

  1. 没有矩形。UI 由弧、笔画、单像素细线构成。否决：面板、边框、九宫格背景、带描边的血条、卡片。
  2. 中心 85% 永远是世界。所有元素活在 7.5% 的呼吸边界内。否决：屏幕中央的任何提示、居中弹窗。
  3. 暖色在 UI 里只有一个含义：热量的存在。否决：用暖色做选中态、hover、按钮高亮、「重要」强调。这会让整套 UI 比一般游戏冷得多。那是对的——这个游戏关于冷。
  4. 没有东西是常驻的。每个元素诞生时就带着自己的死期。否决：常驻状态条、小地图、任务追踪、耐久度、准星。
  5. 提示锚定世界坐标。提示长在门上，不长在屏幕角上。否决：屏幕底部的 “Press E to Interact” 条。
  6. 每一次呵气都有一个声音。视觉与音频同帧诞生。否决：无声的 UI 动作。

The Ruling

被遗弃

GDD §10 的第三种结局：第 8 天黎明有灯是熄的， 直升机从头顶飞过，没有看见你。你还活着。屏幕上什么都没发生。然后画面淡出。

这个结局的 UI 设计，是不存在。

没有标题，没有文字，没有音效，没有淡出提示，没有「返回主菜单」按钮。 直升机飞过去，声音远了，然后画面在 6 秒里淡成黑，再过 4 秒，主菜单在黑里淡入。

任何出现在这里的 UI 元素，都是对这个游戏艺术落点的破坏。 这是一条规则，不是一个风格建议。审查时若发现此处有任何 Control 节点被添加，一律驳回。 tests/unit/test_ui_abandoned_ending.gd 断言该场景树中不存在任何 Control——这是全项目唯一一个断言某处必须没有 UI 的测试。
